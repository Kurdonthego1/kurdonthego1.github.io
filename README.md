# kurdonthego1.github.io

Personal portfolio site for Zana Osman, served at [zanaosman.com](https://zanaosman.com) via GitHub Pages.

Plain HTML, CSS and JavaScript — no build step.

```
index.html            page content (edit text, projects, experience here)
assets/css/style.css  styles + light/dark theme tokens
assets/js/main.js     theme toggle, mobile nav, typing effect, project filters
```

Preview locally with `python3 -m http.server` and open http://localhost:8000.
